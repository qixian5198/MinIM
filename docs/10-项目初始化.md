### Step 3 · 最小可运行应用

`app/main.py`

```python
from contextlib import asynccontextmanager

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from app.api.v1 import router as api_v1_router
from app.core.config import settings
from app.core.exceptions import register_exception_handlers
from app.core.logging import setup_logging


@asynccontextmanager
async def lifespan(app: FastAPI):
    setup_logging()
    yield


def create_app() -> FastAPI:
    app = FastAPI(
        title="MinIM",
        version="0.1.0",
        description="一个最小可用的即时通讯内核",
        lifespan=lifespan,
    )

    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.CORS_ORIGINS,
        allow_credentials=True,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    register_exception_handlers(app)
    app.include_router(api_v1_router, prefix="/api/v1")

    @app.get("/health")
    async def health():
        return {"status": "ok", "env": settings.APP_ENV}

    return app


app = create_app()
```

### Step 4 · 配置与异常骨架

`app/core/config.py`

```python
from functools import lru_cache

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=False,
    )

    APP_ENV: str = "development"
    DEBUG: bool = True
    LOG_LEVEL: str = "INFO"

    DATABASE_URL: str
    REDIS_URL: str = "redis://localhost:6379/0"

    MINIO_ENDPOINT: str = "localhost:9000"
    MINIO_ACCESS_KEY: str = ""
    MINIO_SECRET_KEY: str = ""
    MINIO_BUCKET: str = "minim"

    JWT_SECRET: str
    JWT_ALGORITHM: str = "HS256"
    JWT_EXPIRE_DAYS: int = 7

    CORS_ORIGINS: list[str] = ["http://localhost:5173"]

    @property
    def is_production(self) -> bool:
        return self.APP_ENV == "production"


@lru_cache
def get_settings() -> Settings:
    return Settings()


settings = get_settings()
```

### Step 5 · 统一响应封装

`app/core/response.py`

```python
from typing import Any, Generic, TypeVar

from pydantic import BaseModel

T = TypeVar("T")


class ApiResponse(BaseModel, Generic[T]):
    code: int = 0
    message: str = "ok"
    data: T | None = None
    request_id: str | None = None


def ok(data: Any = None, request_id: str | None = None) -> dict:
    return ApiResponse(code=0, data=data, request_id=request_id).model_dump()
```

## 4. 承重墙登记

以下文件改动风险最高，**改之前先补测试，且单独一个 commit**：

| 文件 | 为什么危险 |
|:---|:---|
| `app/core/security.py` | 鉴权出错 = 全员可越权 |
| `app/core/exceptions.py` | 全局异常出口，改错无错误码 |
| `app/services/message_service.py` | 被所有会话流程依赖，改签名要全量搜调用方 |
| `alembic/versions/*` | 数据不可回滚，必须写 downgrade |

**改动这些区域的流程**：先补测试 → 单独 commit（不与功能混）→ 人工确认 → 立即回归。

---

## 5. 变更预算

沿用工程化规范：

| 项 | 上限 |
|:---|:---|
| 单次变更文件数 | ≤ 5 |
| 单次变更代码行数（不含测试） | ≤ 200 |
| 重构 | 单独算，不与功能混 |

**顺手重构 = 违规。** 不在本次任务范围内的改动一律不做。

## 6. 提交规范

```
<type>: <简短描述>

<正文：说明为什么，不是说明做了什么>

<可选的关联信息>
```

| type | 用途 |
|:---|:---|
| feat | 新功能 |
| fix | 修 bug |
| refactor | 重构（不改行为） |
| test | 补测试 |
| docs | 文档 |
| chore | 构建/配置/依赖 |

**一任务一 commit。commit message 写"为什么"，不写"做了什么"**（后者看 diff 就知道）。

示例：

```
fix: 游标分页在高并发写入下漏消息

原因：原实现用 created_at 排序，同一毫秒内的消息顺序不稳定。
改为用 id 排序，id 单调递增，天然稳定。

另补充了并发写入下的翻页测试用例。
```
