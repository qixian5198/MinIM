## 1. 分层职责边界

| 层 | 职责 | ✅ 可以做 | ❌ 禁止做 |
|:---|:---|:---|:---|
| `api/` | 参数校验、鉴权、调 service、组装响应 | 用 Pydantic 校验入参；Depends 做鉴权/频控 | 写 SQL；写业务判断 |
| `services/` | 业务编排、事务边界、领域事件 | 开事务；调多个 repo；抛业务异常 | import FastAPI 的 Request；直接操作 HTTP 响应 |
| `repositories/` | 数据读写 | 拼查询；返回 model | 写业务判断（"群主才能踢人"属于 service） |
| `models/` | 表结构定义 | 定义字段、关系 | 写业务方法（保持贫血模型） |
| `schemas/` | DTO | 定义出入参结构 | 含业务逻辑 |

**判断标准**：如果一段代码需要 HTTP 上下文才能跑，它属于 api 层；
如果需要数据库才能跑，属于 repository；如果两者都不需要，属于 service（可纯单测）。

## 2. 错误处理规范

### 统一业务异常

```python
# app/core/exceptions.py
class BizException(Exception):
    def __init__(self, code: ErrorCode, message: str | None = None, http_status: int = 400):
        self.code = code
        self.message = message or code.name
        self.http_status = http_status
        super().__init__(self.message)


class NotRoomMember(BizException):
    def __init__(self):
        super().__init__(ErrorCode.NOT_ROOM_MEMBER, "不是该会话成员", http_status=403)
```

### 怎么用

```python
# ✅ 正确：service 抛业务异常
async def get_messages(room_id: int, user: User, repo: MessageRepo):
    if not await repo.is_member(room_id, user.id):
        raise NotRoomMember()
    return await repo.list_by_cursor(room_id, ...)

# ❌ 错误：service 里返回 HTTP 响应
async def get_messages(...):
    if not is_member:
        return JSONResponse(status_code=403, ...)   # 禁止
```

### 全局异常处理器

```python
def register_exception_handlers(app: FastAPI):
    @app.exception_handler(BizException)
    async def biz_handler(request: Request, exc: BizException):
        return JSONResponse(
            status_code=exc.http_status,
            content={
                "code": int(exc.code),
                "message": exc.message,
                "data": None,
                "request_id": request.state.request_id,
            },
        )

    @app.exception_handler(Exception)
    async def unknown_handler(request: Request, exc: Exception):
        logger.exception("uncaught error", exc_info=exc)
        return JSONResponse(
            status_code=500,
            content={
                "code": int(ErrorCode.INTERNAL_ERROR),
                "message": "服务器内部错误" if not settings.DEBUG else str(exc),
                "data": None,
                "request_id": request.state.request_id,
            },
        )
```

### 铁律

| 规则 | 说明 |
|:---|:---|
| **禁止吞异常** | 不许 `except: pass`。至少要 log |
| **禁止裸抛** | 抛 `BizException` 而非 `Exception` |
| **错误码统一** | 一律走 `ErrorCode` 枚举，不硬编码数字 |
| **生产不暴露堆栈** | `DEBUG=False` 时只返回通用错误 |

## 4. 注释规范

**中文注释，写 why 不写 what。**

```python
# ❌ 错误：复述代码
# 遍历成员并推送
for member in members:
    push(member)

# ✅ 正确：解释为什么
# 用 GREATEST 而非直接赋值：客户端可能乱序上报已读位点，
# 直接赋值会导致已读状态回退
await repo.update(
    "UPDATE room_members SET last_read_msg_id = GREATEST(last_read_msg_id, :v) ...",
    {"v": msg_id},
)
```

**什么时候必须写注释**
- 非直觉的实现（如上面的 GREATEST）
- 绕过某个坑的 workaround
- 性能相关的取舍
- 魔法数字的来源

## 5. 各里程碑实现要点

### M1 · 用户与认证

| 要点 | 实现 |
|:---|:---|
| 密码哈希 | `passlib.context.CryptContext(schemes=["bcrypt"], deprecated="auto")` |
| JWT | `python-jose` 签发，payload 含 `sub`(user_id)、`exp`、`type`(access/refresh) |
| 认证依赖 | `async def current_user(token: str = Depends(oauth2_scheme)) -> User` |
| 强度校验 | Pydantic validator：≥8 位且含字母与数字 |

```python
# 认证依赖（所有受保护接口用）
async def get_current_user(
    token: str = Depends(oauth2_scheme),
    user_repo: UserRepo = Depends(get_user_repo),
) -> User:
    try:
        payload = jwt.decode(token, settings.JWT_SECRET, algorithms=[settings.JWT_ALGORITHM])
    except JWTError:
        raise BizException(ErrorCode.TOKEN_INVALID, http_status=401)
    user = await user_repo.get(int(payload["sub"]))
    if user is None:
        raise BizException(ErrorCode.USER_NOT_FOUND, http_status=404)
    return user
```

### M2 · 单聊与消息核心

| 要点 | 实现 |
|:---|:---|
| room 幂等 | 单聊建 room 前先查 `(type=single, 两人都为成员)` 是否已存在 |
| 事务边界 | 在 service 层：写 message + 写 outbox + 更新 room.last_msg_id，**同一事务** |
| 游标分页 | `WHERE room_id=? AND id < cursor ORDER BY id DESC LIMIT limit+1` |
| 敏感词 | 发布前过滤，结果替换 |

```python
async def send_message(
    dto: MessageCreate, user: User,
    msg_repo: MessageRepo, room_repo: RoomRepo,
    session: AsyncSession,
) -> Message:
    # 1. 成员校验（越权第一道关）
    if not await room_repo.is_member(dto.room_id, user.id):
        raise NotRoomMember()

    # 2. 敏感词过滤
    content = sensitive_filter.filter(dto.content)

    async with session.begin():
        msg = await msg_repo.create(room_id=..., from_uid=user.id, content=content)
        await outbox_repo.create(topic="message.new", payload={"msg_id": msg.id})
        await room_repo.update_last_msg(dto.room_id, msg.id)

    return msg
```

**游标分页实现**

```python
async def list_by_cursor(self, room_id: int, cursor: int | None, limit: int = 20):
    stmt = select(Message).where(Message.room_id == room_id)
    if cursor:
        stmt = stmt.where(Message.id < cursor)
    stmt = stmt.order_by(Message.id.desc()).limit(limit + 1)   # 多查 1 条判 has_more

    rows = (await self.session.execute(stmt)).scalars().all()
    has_more = len(rows) > limit
    items = rows[:limit]
    next_cursor = str(items[-1].id) if items and has_more else None
    return items, next_cursor, has_more
```

### M3 · WebSocket 实时推送

```python
class ConnectionManager:
    def __init__(self):
        # user_id -> set of WebSocket（支持多标签页）
        self._conns: dict[int, set[WebSocket]] = defaultdict(set)

    async def connect(self, user_id: int, ws: WebSocket):
        await ws.accept()
        self._conns[user_id].add(ws)

    def disconnect(self, user_id: int, ws: WebSocket):
        self._conns[user_id].discard(ws)
        if not self._conns[user_id]:
            del self._conns[user_id]

    async def send_to_user(self, user_id: int, data: dict):
        for ws in list(self._conns.get(user_id, [])):
            try:
                await ws.send_json(data)
            except Exception:
                self.disconnect(user_id, ws)   # 发送失败即清理
```

| 要点 | 实现 |
|:---|:---|
| 握手认证 | `await ws.accept()` 之前校验 token，失败 `close(4001)` |
| 心跳 | 客户端 ping → 服务端 pong；服务端记录 `last_seen`，60s 超时清理 |
| 断线补偿 | 用 Redis 存最近 N 条事件（带 seq），重连时按 `last_seq` 补发 |

### M6 · Outbox 与文件

```python
async def process_outbox():
    """后台任务：轮询 outbox 并投递"""
    pending = await outbox_repo.list_pending(limit=100)
    for record in pending:
        try:
            await dispatch(record)                 # 推送 / 异步动作
            await outbox_repo.mark_sent(record.id)
        except Exception as e:
            await outbox_repo.mark_retry(record.id, exc=str(e))
            if record.retry_count >= MAX_RETRY:
                await outbox_repo.mark_dead_letter(record.id)
```

| 参数 | 值 |
|:---|:---|
| 轮询间隔 | 1s（或 APScheduler 定时任务） |
| 重试退避 | `2 ** retry_count` 秒，上限 5 次 |
| 死信 | 超过 5 次标记 `status=2`，记日志告警 |
| 清理 | `status=1` 且超过 7 天的记录定时删除 |

## 6. 代码减法原则

| 规则 | 说明 |
|:---|:---|
| 同一逻辑出现第 3 次才抽象 | 第 1、2 次宁可重复 |
| 写新函数前先搜是否已有 | 避免重复实现 |
| **禁止留 `xxx_v2` 双版本** | 要改就改，靠 git 恢复 |
| 删除优于注释掉 | 注释掉的代码是垃圾 |
| 不用过度设计的设计模式 | 本项目只有消息类型、敏感词用了策略模式，其余直接写 |

## 8. 绝对禁止清单

- ❌ 编造不存在的 API / 装没验证过的包
- ❌ 吞异常（`except: pass`）
- ❌ 改承重墙不补测试
- ❌ 一次吐一大坨代码（分模块，每步跑通再往下）
- ❌ 自己写自己审（审查必须开新会话）
- ❌ 顺手重构（不在本次任务范围内的改动一律不做）
- ❌ SQL 字符串拼接（必须参数化）
- ❌ 在 service 层 import FastAPI 的 HTTP 对象
